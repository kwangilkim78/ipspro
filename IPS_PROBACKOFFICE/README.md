# IPS_PROBACKOFFICE

## 기관별 비상연락망

- 기준정보의 `기관·딜러 정보` 바로 아래에 위치하며 기존 `MASTER_DATA` 화면 권한을 사용합니다.
- 기관별 딜러 / IT / 백오피스 담당자를 복수 등록하고 수정할 수 있습니다.
- 등록한 연락처를 선택하고 `수정` 창 하단의 `삭제`를 누르면 기관·업무·담당자를 확인한 뒤 삭제합니다. 다른 사용자가 수정한 연락처는 삭제하지 않으며, 삭제 감사 로그를 남깁니다. 앱 DB 계정에 해당 테이블의 DELETE 권한이 필요합니다. 외부 ETL 딜러 계정에는 영향을 주지 않습니다.
- 담당자명, 회사전화, 휴대전화, 이메일, 연락 순서(1이 최우선), 비고를 입력합니다. 담당자명과 전화번호 한 개 이상은 필수입니다.
- 기본 화면에서 전체 연락망을 조회하며 기관 / 업무 구분 / 검색어로 필터링합니다.
- `ips_ew.institution_emergency_contact` 테이블에 로그인 ID와 등록·수정일시를 저장합니다. 동시 수정 충돌 시 새로고침 후 다시 수정해야 합니다.
- 최초 조회 시 테이블이 없으면 내장된 `Database/v63_emergency_contacts.sql`로 생성합니다. 앱 DB 계정에 CREATE 권한이 없으면 관리자가 해당 스크립트를 먼저 실행해야 합니다.
- ETL 기관·사용자 데이터는 변경하지 않으며 비활성 기관의 기존 연락처도 조회합니다.

### 본인 이메일 설정 및 담당자 메일 발송

- 비상연락망의 `본인 이메일 설정`에서 로그인한 사용자의 회사 이메일을 저장합니다. 기존 `backoffice_user.email`(최대 150자)을 사용하므로 추가 DDL은 필요 없습니다.
- 비상연락망 담당자를 선택하고 `이메일 보내기`를 누르면 메일 작성 창이 열립니다. `보내는 사람`에 발신 이메일을 직접 입력·수정하고 `주소 저장`으로 다음에도 사용할 수 있습니다. 기존 저장 주소가 있으면 자동 입력되며, 발송에는 현재 입력한 주소가 사용됩니다.
- 선택한 행의 이메일이 수신자로 입력됩니다. 제목과 본문을 작성하고 `메일 발송`을 눌러 전송합니다. 수신 이메일이 없거나 형식이 잘못되면 비상연락망 연락처를 수정하거나 ETL 원본 딜러 정보를 확인해야 합니다.
- 기존 사내 SMTP 서버 `mail.ipscorp.co.kr:25`와 필수 STARTTLS를 사용합니다. MailKit 연결에 한해 현재 사내 AntiSpam 인증서의 SHA-256 지문과 유효기간을 검사하여 자체 서명/호스트명 불일치를 허용합니다. 알 수 없는 인증서는 거부하며, 인증서 갱신 시 `ContactEmailTransport`의 지문을 확인 후 변경해야 합니다. 전역 인증서 검증 설정은 변경하지 않습니다. 발신 주소/사내망에 대한 서버 릴레이 허용이 필요하며 실패 시 작성 내용과 상세 오류가 유지됩니다.
- Harness `--contact-email-connection`으로 실제 발송 없이 SMTP 암호화 연결을 확인할 수 있습니다.
- 검증: Harness `--contact-email`은 메일 주소/헤더 검증 및 UTF-8 메시지 생성을 검사하며 실제 메일은 발송하지 않습니다.

## 백오피스 로그인

- `Database/backoffice_login_tables.sql`을 MariaDB `ips_ew`에 먼저 실행합니다.
- 최초 활성 사용자가 없으면 `kikim / 1234`가 `ADMIN`으로 자동 생성됩니다.
- ADMIN은 `백오피스 사용자 관리` 탭에서 직원 계정을 직접 발급합니다.
- 신규 직원은 최초 로그인 시 관리자가 발급한 초기 비밀번호를 반드시 변경해야 합니다.
- 로그인 후 상단 `비밀번호 변경` 버튼에서도 본인 비밀번호를 변경할 수 있습니다.
- 로그인창의 `아이디/비밀번호 저장`, `자동 로그인`을 선택할 수 있습니다.
- 저장된 로그인 정보는 Windows 사용자 전용 DPAPI 암호화 파일로 보관됩니다.
- 프로그램에서 로그아웃한 직후에는 저장 설정과 관계없이 로그인창을 표시합니다.
- 권한은 `ADMIN`, `OPS`, `VIEWER`를 사용합니다.
- 비밀번호는 PBKDF2-SHA256 해시로 저장되고 주요 실행 내역은 `backoffice_audit_log`에 기록됩니다.

`ips_pro`와 `InvoiceReportPrinter_switch_fee`를 하나의 WinForms 실행 프로젝트로 통합한 버전입니다.

- BOK report

- 전체 기관 한도 매트릭스: 활성 기관 전체를 행·열에 배치하고 기관 쌍별 상품 한도를 한 화면에 표시

## 실행 및 배포

Visual Studio 2022 이상에서 `IPS_PROBACKOFFICE.sln`을 열어 빌드합니다. 다른 PC에 배포할 때는 게시(Publish) 결과 폴더 전체를 복사해야 하며, `appsettings.json`, `Templates`, `excel_template`, `reference_rates.csv`가 함께 있어야 합니다.

SFTP 접속 정보는 프로그램 소스에 설정되어 있으므로 별도 환경변수 설정 없이 전송할 수 있습니다.

환율 저장 경로 `Y:\전자거래사업본부\뉴욕종가`와 DB/SFTP 접속 환경은 대상 PC에서도 접근 가능해야 합니다.
